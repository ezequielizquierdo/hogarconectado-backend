# Presentación comercial

`guia-comercial-hogar-conectado.pptx` transforma la guía comercial en una presentación editable de 14 diapositivas, con el lenguaje visual del flyer **Vendé y ganá**.

Los recursos gráficos utilizados se conservan en `assets/` para facilitar futuras actualizaciones.

`operacion-comercial-casos-de-negocio.pptx` explica la atribución de vendedores, las notificaciones y, especialmente, quién cobra, factura, entrega y paga las comisiones en cada escenario. Su desarrollo completo está en `../operacion-comercial-cobro-entrega-y-atribucion.md`.

## Alcance de las propuestas

Las presentaciones combinan capacidades actuales con el modelo comercial objetivo. La operación vigente del piloto para productos propios usa 60% del margen para el vendedor y 40% para Hogar Conectado. El reparto 60/30/10, la liquidación multiparte, la compra inmediata y los pagos integrados se presentan como evolución propuesta; no deben comunicarse como funciones ya habilitadas. La referencia operativa vigente es `../piloto-operativo-vendedores.md`.
